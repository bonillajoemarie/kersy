## Global Constraints (all Phase 1 constraints still bind, plus)

- Palette tokens EXACTLY: `--active #d95926`, `--idle #3987e5`, `--stale #8a8a86`, `--accent #CC7832` (brand/UI only, never a data color), `--success #0ca30c`, `--error #d03b3b` (icon+label paired ONLY), surfaces `--bg #2B2B2B`, `--panel #3C3F41`, `--panel-hi #45494A`, `--inset #242424`, `--border #323232`.
- No raw UUIDs/hashes/numbers as visible labels anywhere (IDs → tooltips only).
- 0%-idle rule: any new animation (glow, camera lerp, spawn ease) must terminate; camera lerp stops when |delta| < 0.1px.
- No new JS runtime deps; no new Rust deps; fonts as local assets only.
- `run_prompt` NEVER interpolates into a shell string (Command::arg array), cwd validated against discovered projects.
- Every empty state teaches; every disabled control explains itself (title attr).

### Task 1: Backend — fsx module: `list_dir`, `run_prompt`, `cli_available` (+ project paths in DiscoveryDone)

**Files:** Create `src-tauri/src/fsx.rs`; Modify `src-tauri/src/lib.rs`, and kersy-core ONLY IF needed to expose project slugs→paths (prefer computing in shell via `kersy_core::claude::project_dir_to_path`).

**Interfaces (produces — UI tasks consume verbatim):**
```rust
#[derive(Serialize)] #[serde(rename_all="camelCase")]
pub struct DirEntry { pub name: String, pub is_dir: bool }
// commands:
list_dir(state, path: String) -> Result<Vec<DirEntry>, String>   // canonicalized path must start with a discovered project's canonicalized real path; dirs-first, case-insensitive sort; skip entries whose name starts with "." is NOT done (frontend dims them) but .git/node_modules/target ARE returned (frontend collapses)
run_prompt(state, project_path: String, prompt: String) -> Result<(), String>  // path validated same way; spawn detached: Command::new("claude").args(["-p", &prompt]).current_dir(&path).stdout(log).stderr(log).spawn(); log file: dirs::data_dir()/kersy/prompt-logs/<epoch-millis>.log (create dirs)
cli_available() -> bool   // std::process::Command::new("claude").arg("--version") spawn+wait ok, cached in a OnceLock
```
App state gains `project_paths: Vec<PathBuf>` (canonicalized real paths of discovered projects, built at startup from slugs; missing dirs excluded). `subscribe` additionally sends project paths — extend `DiscoveryDone` with `projectDirs: Vec<{slug: String, path: String, exists: bool}>` (camelCase; additive field, UI type updated in Task 3).
