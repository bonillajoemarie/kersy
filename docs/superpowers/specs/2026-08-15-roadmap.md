# Kersy — roadmap

**Purpose (owner, 2026-08-15):** a personal cockpit — monitor agents, the workspace, and the task list in ONE layout. Single user (Joe), own machine first (Fedora), portable to Windows/macOS. YAGNI applies hard: no multi-user, no telemetry, no product polish beyond what one person needs daily. If it proves useful, the owner may hand installers to the team — auto-discovery + per-OS installers already cover that; still each user monitoring their OWN machine (no central server).

Stack locked: **Rust + Tauri 2**, core logic in a GUI-free Rust library crate, TypeScript + canvas UI. Each phase = its own spec → plan → implementation cycle.

## Phase 1 — Agent Map (specced: `2026-08-15-agent-map-design.md`)
Live machine-wide monitor: animated force-directed graph of projects → sessions → subagent trees, current tool/shell command per agent, drill-in activity feed, **always-visible task list pane** (from `~/.claude/tasks`), launch-time OS-aware auto-discovery of Claude data roots. Read-only. Installable (RPM/AppImage now; .msi/.dmg from same repo).

## Phase 2 — Workspace shell
Directory browser (Rust fs commands) + **CodeMirror 6** editor (lightweight/fast; deliberately not Monaco) in a split layout; the agent map and task list dock as panes so agents + files + tasks share one window. Read/edit/save, syntax highlighting, fuzzy file open. No AI.

## Phase 3 — AI prompt, multi-model
Chat pane with a two-lane provider layer:
- **Subscription lane (default):** drive locally installed agent CLIs headless — Claude Code (`claude -p` / Agent SDK, existing Team-plan login), Codex CLI (ChatGPT plan), Gemini CLI. Detected in the same discovery pass as data roots; appear in the model picker automatically. Sessions launched this way write to `~/.claude/projects`, so they appear live on the agent map — prompt and monitor form one loop.
- **Key lane (optional):** direct Anthropic/OpenAI APIs + local Ollama; keys in OS keychain. Never required.

## Phase 4 — AI acts on the workspace (own brainstorm later)
Agent-mode editing: the AI modifies files/executes with approval gates. Deliberately deferred; largest risk surface.
